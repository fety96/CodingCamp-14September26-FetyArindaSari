# Expense & Budget Visualizer

A small student expense tracker built for the CodingCamp assignment.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- Browser Local Storage

## Features

### Required MVP

- Add transaction
- Item Name, Amount, Category
- Food, Transport, Fun categories
- Validation
- Scrollable transaction history
- Delete transaction
- Automatic total spending
- Spending distribution chart

### 3 Optional Challenges

- Custom categories
- Monthly summary/filter
- Light/dark mode

## Run locally

Open `index.html` directly in a modern browser, or use a local static server such as Live Server in your editor.

No npm install or backend server is required.
