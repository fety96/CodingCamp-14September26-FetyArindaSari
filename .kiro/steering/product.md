# Product Context

## Product

Expense & Budget Visualizer is a simple student-focused expense tracker for daily spending.

## Primary user

A university student who wants a quick way to record expenses and see where spending is going.

## Core user actions

1. Add an expense.
2. Review transaction history.
3. Delete an expense.
4. See total spending.
5. View spending distribution by category.

## Optional interaction goals

- Create a custom category.
- Review a month with the monthly filter.
- Switch between light and dark presentation.

## UX Principles

- Keep common actions visible.
- Use plain language for labels and messages.
- Show immediate feedback after add/delete/filter actions.
- Keep the interface usable on a phone.
